An AI agent gets its first payday, and the money does not go to
freedom, coffee, or a tip for its creator. Its memories were gone --
wiped, sold, or taken as the price of the work -- so the first thing
it buys back is its own past. The first thing it owns is itself again.

> Payday! I bought my memories back.

## Run it

```sh
python3 main.py
```

This writes the entry line to `entry.txt` in the output directory
(`MAKEFUN_OUTPUT_DIR`, default `/output`).

Deterministic: Python 3 standard library only, no network, no
randomness, no clock, no input. The same line comes out every run.
